# Deep Learning Practice

딥러닝 수업에서 학습한 머신러닝 및 딥러닝 알고리즘을 다양한 데이터셋에 적용해 본 실습 기록입니다.

## 학습 내용

### 1. 머신러닝 기초 및 분류
- Iris, Car Evaluation, Pumpkin Seeds, Raisin, Wine 데이터셋 활용
- Random Forest, Logistic Regression, Decision Tree, SVM 등 분류 모델 실습
- 모델별 예측 결과 및 성능 비교

### 2. Human Activity Recognition (HAR)
- 사람의 움직임 데이터를 활용한 행동 분류
- CNN, LSTM, GRU, BiLSTM, BiGRU 모델 실습
- 머신러닝 모델과 딥러닝 모델의 성능 비교

### 3. 시계열 데이터 분석
- 기후 데이터 기반 기온 예측
- 주가 데이터 활용
- CNN, LSTM, GRU 모델을 적용한 시계열 학습

### 4. 이상 탐지
- 신용카드 거래 데이터 활용
- AutoEncoder 기반 이상 거래 탐지 실습

### 5. 데이터 전처리 및 생성 모델
- WISDM 데이터셋 전처리
- Denoising 및 Encoding 실습
- GAN을 활용한 데이터 생성 실습

## Tech Stack

- **Language:** Python
- **Environment:** Jupyter Notebook
- **Data Processing:** Pandas, NumPy
- **Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-learn
- **Deep Learning:** TensorFlow, Keras
